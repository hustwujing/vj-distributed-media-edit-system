# Agent 提示词与上下文优化验收报告

日期：2026-11-03。最终状态与版本见下方发布记录。各次运行独立保留结果，不把模型未交付或检查器失败追改为成功。

## 改动范围

实现与检查项见 [设计文档](agent-prompt-optimization.md)。本轮包含公共规则与规划/执行/步骤验收/诊断/最终验收职责分离；只沿明确任务关系收集质量反馈；保留版本、来源和分页查询；提供真实剩余预算；按需获取操作契约；原生恢复减少重复历史；新会话通过公开历史交接；生成提示保留用户原始要求和参考图职责。用户硬要求、技术必要条件和审美建议分开，已确认验收标准不降级。

沙盒能力发现默认返回精简索引，具体 schema 用 `capabilities --operation ID` 获取；`--full` 显式获取完整目录。接口和操作能力未删除，未知字段与权限继续由程序校验。提示增加完整计划 JSON 的 preflight 用法及标准库文件校验说明。

同轮修复：HTTP 页面缺少 `crypto.randomUUID` 时使用 `crypto.getRandomValues` 生成 UUID v4；恢复沙盒 `file(1)` 所需的只读 magic 数据库并纳入运行时指纹。

## 真实验证与优化依据

第一轮版本 `cabfbc253c1f` 通过 722 项 Python、47 项前端测试，以及 8 项隔离浏览器配置切换检查。真实字幕任务、外部图片消除、重新规划与成果复用、Claude/DeepSeek 连续恢复及切换均完成。

字幕任务第一轮输入 Token 高于原始样本。检查实际工具事件发现 Agent 默认读取完整能力目录，并多次读取大段 helper 源码。这些工具结果随原生历史重复进入后续请求，因此第二轮将发现入口改为精简索引，提示先查对应接口，再为具体问题读取相关源码。

最终服务配置下，同一能力目录序列化为 UTF-8 JSON：完整目录 64,864 字节，精简索引 11,488 字节，减少约 82.3%；按 `media.edit` 查询提供实际登记的 schema 与补充调用说明。24 步合成工作流的单步验收证据从 25,810 字节减少至 7,935 字节，保留目标详情和其他步骤索引；最终验收仍包含全部步骤。以上为上下文结构指标，不等于实际 Token 降幅。

## 真实测试追加发现

第二轮真实任务中，Agent 读取 `/workspace/capabilities.json` 得到空内容。根因为只读索引先挂载、工作区父目录后挂载，将索引覆盖成工作区空占位文件；CLI 获取能力不受影响。调整为先挂父目录、再挂只读子文件。原测试只断言文件存在，已加强为降权沙盒内解析真实 JSON、核对操作列表及精简视图，并验证写入被拒绝。这是通用运行环境修复，没有针对用例文本匹配。

直接在未准备运行时的源码目录执行定向测试时出现网关文件访问权限与旧 magic 运行包错误（62项：1失败、4错误、5个未启用真实模型的跳过）；此结果没有用于发布。后续使用标准 prepare-executor 准备的冻结版本运行全量门禁，最终结果以下方记录为准。

第二轮字幕任务改走 `media.edit` 工作流。模型没有声明转写输入，并反复在参数中猜测 transcript 字段，运行时三次拒绝；两次修复额度耗尽后失败终止，没有渲染、发布或遗留未结束调用。模型将原因解释为“契约不一致”不是已经核实的程序结论：实际错误是未绑定输入和使用不支持字段。该轮不计成交付通过，也不用于与单次脚本执行作等价性能比较。

第二轮 R17 已正确复用亮度产物并使用 `image.batch_export` 输出32×24 PNG，但测试检查器只将 `image.local_adjust` 计入 local_image 额度，误报重复执行。检查器改按实际登记的 fixed_image 执行器统计全部新步骤，并在清理前保存调用账本和额度记录。原失败证据保留，后续用新独立项目重新验证，不追改旧结果为通过。

挂载修复版本31d6174724dd上的字幕和图片测试进一步暴露说明不足：固定媒体自由结构未解释完整素材/转写绑定；图片规划额外要求中间产物无Alpha，而实际固定工具返回全不透明RGBA。两条均保留候选或错误并安全暂停，未交付，不计为自动成功。随后补充通用 usage_guidance、固定媒体入口参考以及按阶段验收和Alpha语义说明；没有修改业务验收、授权或自动批准逻辑。

暂停页独立核对通过：字幕5条规划消息/22条执行消息，图片7条规划消息/11条执行消息全部与服务端一致，错误原文一致且工具转圈为0。检查器最初假设暂停页也使用终态消息卡，导致超时；按实际暂停状态的连续正文比较后通过，产品渲染逻辑未因此改动。

## 验证边界

本轮覆盖改动相关真实场景，没有重新执行历史60或77条全部场景。实际模型 Token 以调用回执统计，`prompt_context.characters` 只代表宿主本轮消息字符数，不含 SDK 历史和后续工具输出。`media.edit.edit_plan` 仍是自由结构，嵌套媒体输入的部分检查发生在运行时；usage_guidance补足说明，不等于新增了完整嵌套静态schema。模型可能仍出现错误参数、缺工具或质量偏差；程序应拒绝无效操作、保留事实并按既有机制处理，不能靠提示承诺永不发生。
