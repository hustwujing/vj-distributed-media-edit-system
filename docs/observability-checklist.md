# 可观测性专项验收清单

24 项在声明范围内全部通过。当前发布 `cd52b77407b0`。实现、静态审查、测试与证据见 [机器清单](observability-checklist.json)及 [实施报告](observability-implementation-report.md)。

| 编号 | 阶段 | 状态 | 要求 | 验收标准 |
| --- | --- | --- | --- | --- |
| OBS001 | O1 | 通过 | 统一结构化日志与字段 | API、worker、watchdog、解码服务和网关日志可被同一解析器解析，具备版本、实例、级别、事件及适用关联字段。 |
| OBS002 | O1 | 通过 | HTTP 关联与错误编号 | 正常/异常响应均有 request_id，页面可复制查询；客户端关联头经过校验且不参与授权。 |
| OBS003 | O1 | 通过 | 跨进程与跨节点关联 | 并行任务不串上下文；重试、轮询、重启和接管可关联原任务、步骤修订及各自 attempt/span。 |
| OBS004 | O1 | 通过 | 外部调用关联 | 提交、查询、收取、取消关联 request_key、attempt、上游任务 ID 与供应商请求 ID；缺失字段明确标识。 |
| OBS005 | O1 | 通过 | 持久化事件一致性 | 事务回滚、强杀及旧代次提交场景中，诊断不会将意图或日志输出当作已提交成功；关键状态变化可追溯。 |
| OBS006 | O1 | 通过 | 异常根因与容错审查 | 代码异常可定位脱敏堆栈与因果链；逐项审查静默捕获；预期取消/排空/租约丢失不混报代码故障。 |
| OBS007 | O1 | 通过 | 子进程与资源证据 | 记录退出码、信号、超时、资源限制/OOM 证据及有界输出，不能凭退出码猜测根因。 |
| OBS008 | O1 | 通过 | 脱敏与输出边界 | 含伪造密钥、Cookie、签名 URL、用户内容和换行注入的测试不泄露敏感内容；字段、嵌套和输出量受限。 |
| OBS009 | O2 | 通过 | 单任务诊断摘要 | 只给 task_id/request_id 即可查到状态、等待、最近进展、节点、版本、错误及证据，无需手工拼 SQL。 |
| OBS010 | O2 | 通过 | 完整时间线与成果 | 显示步骤修订、尝试、接管、上游、产物/checkpoint 与清理；关联顺序在并发和时钟偏差下不误导。 |
| OBS011 | O2 | 通过 | 等待解释与用户展示 | 区分排队、依赖、资源、上游、收取、验收和清理，显示持续时间及下次动作，无未知进度的伪百分比。 |
| OBS012 | O2 | 通过 | 只读与安全恢复建议 | 诊断不修改状态、不触发生成/重试；建议依据已保存证据，不将未知上游状态标为已失败或已取消。 |
| OBS013 | O2 | 通过 | 权限与诊断包 | 跨项目/越权查询及导出被拒绝；运维入口受限；导出有脱敏、版本、时间窗及证据缺失说明。 |
| OBS014 | O2 | 通过 | 故障时诊断降级 | 数据库/节点不可达或日志部分缺失时仍返回可取得的证据和明确缺口，不伪造完整成功。 |
| OBS015 | O3 | 通过 | 指标覆盖与语义 | 覆盖队列、阶段、资源、上游、取消、清理、存储和观测降级；并行累计耗时与墙钟耗时明确区分。 |
| OBS016 | O3 | 通过 | 高基数控制 | 任务、用户、请求和上游任务 ID 不进入指标标签，日志/追踪可按 ID 检索。 |
| OBS017 | O3 | 通过 | 采集检索与看板 | 跨 API/worker 查询可统一检索，集群/任务/上游/存储视图可关联原始证据及发布版本。 |
| OBS018 | O3 | 通过 | 容量留存与查询预算 | 留存、轮转、容量上限、索引及分页配置明确；负载验收报告数据规模、P95、采集延迟和资源预算。 |
| OBS019 | O3 | 通过 | 观测故障不改变业务 | 采集器停机、日志磁盘满、遥测写入故障有降级/丢弃证据；无无限缓冲、阻塞或收费任务重提。 |
| OBS020 | O4 | 通过 | 告警闭环 | 节点失联、队列无进展、上游未知、清理超期、5xx、存储/容量故障触发本地测试告警并验证恢复、去重与维护静默。 |
| OBS021 | O4 | 通过 | 健康与通知配置 | 区分存活、就绪、依赖及业务健康；通知渠道未配置如实显示，测试不向未授权收件人发送消息。 |
| OBS022 | O4 | 通过 | 部署与操作手册 | deploy.sh 管理观测组件/配置/状态；部署、停止、恢复和回退可演练，告警附影响范围和排障入口。 |
| OBS023 | O4 | 通过 | 实际故障排障演练 | 覆盖 HTTP 500、脚本失败/OOM、同步超时、异步提交未知、强杀接管、DB/BOSS 故障、取消晚到结果和清理失败。 |
| OBS024 | O4 | 通过 | 通用接入与最终验收 | agent/manual/workflow、script/operation、新处理器复用观测契约；每步 review/单测/功能测试及整体回归均有版本化证据。 |
