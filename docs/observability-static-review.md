# 可观测性静态审查

本记录针对本次源码；最终版本、完整测试与现场证据以实施报告为准。

| 范围 | 核对与处理 |
| --- | --- |
| 业务一致性 | 状态审计由 SQLite/PostgreSQL 同事务触发器写入，回滚同时撤销；日志仅记录意图/观测，不能推进任务或重发上游。 |
| 请求归属 | HTTP ID 服务端生成；任务关联与提交同事务。项目诊断先验证所有者，再验证任务归属；运维数据仅 root CLI 或 loopback Bearer 接口。 |
| 长程与并发 | task 稳定、attempt/span 分开；ContextVar 防线程串扰，worker 包装器和网关显式带 task/attempt。阶段调用结束就关闭 span，不挂起等待整个上游任务。 |
| 敏感数据 | 日志字段白名单，无自由文本消息、参数、源码行、环境或对象 URL；凭据值再过滤；堆栈只保留异常类/模块/函数/行号。诊断不直接导出业务 JSON、Cookie、authorization 或 checkpoint manifest。 |
| 异常路径 | executor 的执行、续租、settle/close；reaper 的启动、数据库观察、外部清理扫描及隔离；网关 broker；媒体解码；阶段计量和 HTTP 错误补充安全事件。重新抛出的异常由 phase/入口捕获，预期控制流不当作代码错误。 |
| 允许的容错 | collector 解析/磁盘失败计 dropped，HTTP 查询失败返回 503，存储探测返回 unavailable；SDK/本地资源的不存在/进程已退出等幂等容错保留。watchdog 数据库失败后仍执行本地许可到期保护。 |
| 子进程证据 | 进程退出与信号独立记录；cgroup v1 oom_control / v2 memory.events 提供 OOM 证据，无证据不猜测。 |
| 诊断可靠性 | 不记录用户提示词/脚本/媒体；按索引有界查询，日志截断及部署前历史缺少关联时明确 partial；数据库不可达仍可查询独立采集器。 |
| 查询与部署 | CLI 从 release.json 导入已部署应用；默认摘要，导出 O_EXCL + 0600；集中接口不接受 SQL/文件路径，仅字段过滤与分页。 |
| 容量隔离 | 非阻塞有界输出队列、采集器独立磁盘与服务资源预算、HTTP 并发上限、留存轮转；业务不等待采集器。 |
| 指标 | 禁止高基数 ID 标签；阶段累计与任务墙钟分开；HTTP 延迟定义为响应头时间，GPU、DB、对象存储健康分别提供。 |
| 告警 | 本地历史记录状态转换，具备持续窗口/去重/恢复/维护静默；外部通知未配置如实展示，未向任何人发送消息。 |
| 发布与凭据 | 新配置 0600，unit 引用 EnvironmentFile，不把 token 写入 argv/URL；media 不加载观测 token，网关过滤 TOKEN/KEY/SECRET。备份包含实例私有配置。 |

专项故障测试覆盖真实 PostgreSQL、HTTP 服务、S3 协议替身、cgroup 和进程失败；全量测试复核原调度、取消、接管及媒体能力。没有通过诊断去修复或重提测试任务，故障注入均使用隔离数据。

## 现场与真实子进程复核发现的修复

- 上游 HTTP 响应的追踪头为可选信息；增加类型检查与容错，避免不同 SDK/测试响应影响原有业务结果。
- 本地与分布式图片面板均走真实用户提交和实际沙箱执行。真实 PostgreSQL/S3 用例复现 ImageRelay 子进程遗漏共享数据库配置的问题；补充最小配置传递后通过，未扩大模型或对象存储凭据范围。
- 独立外部清理子进程补充分布式 bucket 声明与受控日志上下文；使用真实降权子进程验收 unsupported 语义，不重新提交生成。
- 所有短生命周期清理/网关子进程输出到 stderr 并在正常退出时有界刷新；避免 stdout 协议、DEVNULL 或立即退出吞掉根因。
- 图片工具、manual 执行器及网关内部捕获异常补充结构化错误；固定工具可产生有界错误信封。父进程只采纳白名单错误字段，子进程不能伪造其他任务的关联信息。
- PostgreSQL 已安装审计触发器不再在每个 API/worker 启动时 DROP/CREATE，避免与只读扫描形成表锁死锁。真实 PostgreSQL 测试持有任务表读锁并重新初始化，确认不会申请不必要的排他锁。
- 部署单测的模块级 ROOT 改为临时目录，防止测试维护标记写入实际观测目录。
- journal 普通启动文本不算丢失的遥测；API 定期只读探测保持采集链可验证，避免把业务空闲误报为采集器卡死。

- 阶段计量改用独立短预算连接，不继承业务连接的长控制锁等待；真实 PostgreSQL 持锁测试验证计量降级不会抛业务异常，控制状态仍遵守原有强一致事务。
