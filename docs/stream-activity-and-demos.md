# 文字流、实时执行状态与共享示例库

后续真实项目暴露的网关尾部缓冲、终态正文覆盖、旧说明回退及规划成本问题，另见 [执行体验优化待办](agent-execution-experience-todo.md)。下文记录此前版本的实现与验收，不代表这些后续问题已解决。

## 已确认的问题

- 发布中的 `.venv` 是符号链接，原递归 ACL 命令没有覆盖其依赖目录。API 账号导入 Redis 时得到缺少 Redis 类的命名空间包，实时通道静默降级为数据库快照。生产环境已用同一配置分别在 root / video-use 身份下复现。
- 沙盒 Agent 在每个 SDK 通知上查询完整任务、调度和工作流快照，造成事件处理滞后；单条 agentMessage 完成时又没有立即发布完整正文，尾部文字会一直等到后续输出或任务结束。
- 页面定时快照可以覆盖更新的增量文字；光标按“任务仍运行”闪烁，不能区分模型输出与工具运行。
- 原 44 个示例及 219 个文件仍在 workspace/demos，但分布式 API 节点目录缺少示例库，接口按节点本地路径读取而返回空数组。

## 修改

1. 准备运行环境时解析 `.venv` 的真实目录再赋予服务读取权限，并用 API 身份检查 fastapi、psycopg、redis 的实际导入。私有配置不在授权范围内。
2. 统一 TextPublisher：按租约代次和序号标记文本，单条消息完成立即发送完整快照并落库；Redis 不可用仍可从数据库及时恢复。完成任务发送权威全文。
3. SDK 接收循环每 250 毫秒核实取消/租约，工具和正式写入仍保留原有即时权限校验；不再逐通知构建完整任务快照。网页按动画帧批量渲染，拒绝旧版本覆盖，缺失增量时重连补齐；仅实际输出阶段显示光标。
4. 持久化可观察的执行主体与动作：轻量 Agent、沙盒 Agent、工作流沙盒、宿主程序、媒体执行器、外部服务。记录模型等待/分析/公开回复、工具准备、文件修改、命令执行、操作提交/查询/收取/验证和检查点保存。并行步骤分别显示，上游等待在轮询间隙仍可见。只使用结构化事件，不展示内部推理文本。
5. 观测阶段使用短超时、独立事务及异步实时通知；不等待调度控制锁，不改变业务权限。事件与 task/attempt/step 关联，日志含 actor、activity_id、phase、operation。
6. 示例库复用现有加密对象存储，PostgreSQL 保存版本化目录；全部文件就绪后原子切换目录。请求固定使用同一版本，失败导入保留旧版本，不跨用户共享私有成果。载入后的素材、转写和初始编辑计划也持久化，新节点可恢复。
7. 部署在切换服务前同步共享示例库，并在两个 API 节点检查目录及实际封面；首页区分“未初始化”与“无匹配结果”。

## 审查与过程修正

- 原 44 个示例的全部引用均存在，合计 219 个文件、100262003 字节；未重新生成媒体或调用付费图片/视频服务。
- 补齐 Redis 故障日志，异常记录类型而不输出连接凭证；实时通道失效时显示快照同步，并可重新接回 Redis。
- 消息版本阻止迟到 HTTP 轮询覆盖实时内容；迟到活动不能把已完成工具恢复成“运行中”。
- 完整回归发现观测记录会等待业务控制锁，已改为独立短预算写入；原锁竞争性能测试保留并通过定向复测。
- 权限测试最初受已安装 Redis 和复制来的 ACL 影响，已在隔离目录清除 ACL，并禁用系统 site-packages，确保确实验证目标依赖的读取权限。
- 浏览器截图脚本曾匹配到多个历史执行面板，已限定当前消息；这是测试驱动错误，未改变业务完成判断。
- 沙盒子进程首次测试缺少新工作区模块的读取 ACL，按现有代码读取规则补齐；发布脚本会为全部模块执行同一准备步骤。
