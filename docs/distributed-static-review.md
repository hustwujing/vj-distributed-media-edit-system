# 分布式静态审查记录

本记录覆盖控制面、对象存储、步骤/实现契约、输入输出、取消及清理边界。代码编译、完整测试和真实BOSS验证为附加证据，不替代本记录。

- PostgreSQL事务级advisory lock统一保护跨表配额、领取和取消；只读监控连接不取该锁。数据库时间保留亚秒；SIGKILL未提交事务会回滚，不用宿主时钟作为租约权威。
- 业务执行按attempt/generation/step slot校验。同一工作流分支可并行，根Agent及验收与分支互斥。接管只重置目标步骤，不能误重跑其他活跃分支。
- 输入由归属、角色、已验收修订和hash共同约束。脚本/会话checkpoint与步骤输出checkpoint分开；分支不能覆盖整个项目快照。汇合测试实际读取两条已验收分支，原节点目录已删除。
- 发现取消事务缺少独立可审计请求，补execution_cancel_requests；取消、业务停止、验收失效和清理意图同事务提交，重复取消返回同一request_id。完成任务不反向变成cancelled。
- 发现外部响应先保存Cookie再保存任务ID会在取消竞态丢失句柄；改为同事务保存ID/会话，失去业务权限后受限late_receipt只登记上游事实和清理，不恢复业务。
- 发现外部清理缺少明确owner/generation/deadline，新增并在回执更新时校验。过期清理worker不能覆盖接管者结论；accepted不等于cancelled，实际succeeded/failed与用量如实保留。增加只查既有ID的管理reconcile入口。
- 本地监控为进程内统一observer/watchdog，批量查询本实例活跃任务。停止回调在有限线程池中执行，单个阻塞/异常不阻塞观察线程；本地许可到期后sticky停止，数据库断连不能延长许可。无法中断的S3 SDK在专用进程执行。
- 对象先上传后提交引用；陈旧租约、取消和修订变化拒绝发布。上传预占计入额度。GC先标记deleting再远程删除，有引用对象不能被删除，tombstone处理晚到PUT。新增逻辑引用替换后的无引用旧对象进入延迟回收。
- 缓存以项目及hash复用，每次验证大小/hash；污染重新下载，缺失或损坏远端文件不进入执行。大文件工作区支持硬容量ext4 loop与tmpfs，回收后卸载。
- ai-tool BOSS真实探测确认读写/删除/If-None-Match可用，同时确认桶匿名可读。接入流式AES-256-GCM：每对象随机nonce，key标识与长度头、对象key作为认证数据；认证通过前不暴露明文。节点共享私有密钥，不能把checkpoint明文直接放公开桶。
- BOSS对象键在独立video-use前缀内；实测使用随机integration前缀，测试后仅删除自身数据库记录的对象，不列举或修改其他应用对象。源凭据和加密密钥只在gitignored私有文件。
- operation与实现版本、生命周期分离。新增受信任handler和替代实现通过注册，参数schema与校验同源；调用者不能用不同业务实现、未知版本或URL越权。媒体Worker未知action直接拒绝。
- 补充核对内置能力的替代实现：参数契约和业务校验继承原operation，不按替代executor名称误查图片模型；主实现允许从非`@1`版本开始。两项均有独立回归用例。
- 执行意图固定每个operation批准的实现；工作流未指定实现时继承该绑定，显式换实现会被拒绝。外部调用次数按实际外部副作用判断，不能利用retry_safe绕过已批准调用数。
- 供应商并发按提交时保存的provider_class计数，不按当前默认实现推断；替代后端和默认配置变化不能绕过共享额度，查询已存在任务不受新提交额度阻挡。
- 增加节点operation白名单在候选和原子领取双重检查；已排空worker不领取新业务；环境fingerprint不符的本地步骤不能接管。能力配置存在和上游健康仍明确区分。
- 事件附带step、revision、attempt、generation、implementation；分阶段墙钟指标可跨API读取，嵌套阶段不能简单累加成CPU耗时。
- 测试修正保留原业务断言：固定抠图夹具需真实工作流修订/授权；纯提交与等待不再创建沙盒，收取之后才断言资源清理。新增源码的低权限broker读取ACL按既有规则补齐，未重启生产服务。

- 额外验证受信任低权限broker通过私有stdin取得必要存储认证和加密密钥，执行加密文件写入；普通任务沙箱环境没有这些变量。补齐新安装依赖的服务账号读取ACL，不授予数据目录或私有配置读取权限。加密API和实际broker跨节点读取测试通过。
